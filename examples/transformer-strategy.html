Power Transformer Failure Mode Analysis

The three observed failure modes for TX-001 have severity scores 8, 6 and 9. For this screening exercise, each has occurrence score 3; the scores are illustrative and are not a calibrated failure probability.

let assetName = "TX-001 <north>"
let severity = [8, 6, 9]
let occurrence = 3
let modeScores = for severityScore in severity {
  return severityScore * occurrence
}
let totalScore = 0
for score in modeScores {
  totalScore += score
}
let action = match totalScore {
  case 69 => "Inspect cooling system"
  default => "Review operating history"
}
