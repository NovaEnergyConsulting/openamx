Asset Fleet Risk Analysis

Three assets are screened at five points per ordinal exposure level. This is a comparative index, not a probability or financial forecast.

let fleetName = "North & South fleet"
let exposures = [1 to 3]
let riskPoints = for exposure in exposures {
  return exposure * 5
}
let fleetScore = 0
for points in riskPoints {
  fleetScore += points
}

Portfolio decision

The final fleet score is 35 across 1, 2, 3 exposure levels.

An additional five points reflect a shared access constraint. The classification uses a literal case for a critical score and a default for other scores.

  default => "Schedule review"
}
