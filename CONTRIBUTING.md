# Contributing

Thank you for your interest in contributing.

## Dual Licensing Model

This project is distributed under:

- AGPLv3
- Commercial licences issued by Nova Energy Consulting Pty Ltd

To preserve the project's dual-licensing model, contributions must be capable of being distributed under both licensing arrangements.

## Contributor Agreement

By submitting a contribution, including code, documentation, tests, examples or other materials, you represent that:

1. You have the legal right to submit the contribution.
2. The contribution is your original work or appropriately licensed.
3. You grant Nova Energy Consulting Pty Ltd a perpetual, worldwide, non-exclusive, irrevocable licence to use, modify, distribute and relicense your contribution under:
   - AGPLv3; and
   - Commercial licensing arrangements for this project.

## Code Standards

Contributions should:

- Follow the project coding standards.
- Include appropriate tests where practical.
- Include documentation updates where required.
- Avoid introducing unnecessary dependencies.

## Pull Requests

Please include:

- Description of the change
- Reason for the change
- Testing performed
- Any known limitations

## Code of Conduct

Be respectful and professional.

Constructive feedback and collaboration are encouraged.
