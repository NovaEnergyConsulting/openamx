## Comparison Policy

- Exact: export names/keys, value types, record/list order, measurement
  dimension and display unit, diagnostic identity, view discriminants/order,
  table/chart labels/headings, null locations, diagram schema and primitive
  membership.
- Floating: each case lists absolute and relative tolerances based on
  equivalent JavaScript Number operation order. No blanket loose tolerance.
- Errors: compare AMX code/message/file/line/column where the generated helper
  has source context. Do not compare JavaScript stack traces or generated TS
  line numbers as AMX coordinates.
- Generated bytes: record SHA-256 and exact compiler config; a matching hash is
  deterministic-artifact evidence, not parity proof by itself.
- D122-15: no AMX parity row for enum-valued record defaults that current AMX
  cannot express. Record the exclusion and retain direct helper tests separately.

## Reconciliation

Before owner disposition, reconcile every `G123-*` ID to a named test and raw
status, audit all unique current AST discriminants against exactly one lowering
row, map every S123 master-plan bullet, and compare generated imports against
the final S122 public declaration. The unique AST map is present; its golden
and parity coverage is not yet complete. Unsupported or untested rows stay
`BLOCKED/UNAVAILABLE` or `NOT RUN`, never inferred PASS.
