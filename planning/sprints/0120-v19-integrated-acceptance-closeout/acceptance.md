# Sprint 120 Acceptance Criteria

Sprint 120 is complete only when S115-S119 are reconciled, all required V0.19
end-to-end feature paths have reproducible evidence, raw focused/broad/build/
extension/desktop/artifact results are recorded, accepted residuals are named,
and a separate product-owner closeout disposition exists. Sprint 120 adds no
product behavior and authorizes no release action.

## Entry and Authority

- S115, S116, S117, and S118 accepted dispositions are verified without
  contradiction. Sprint 119 is verified ACCEPTED/CLOSED WITH RECORDED RESIDUALS.
- The entering residual is explicit: full VS Code host 20 pass/9 fail on
  unrelated Windows cleanup/path-case tests, while V0.19 grammar/format/
  diagnostic host cases pass.
- Separate S120 authorization records exact baseline, preservation, commands,
  artifact roots, retry policy, and changed-path rule before execution.
- No source/test/spec/example/generated/package/release fix occurs in S120.

## Chart End-to-End

- Parser/checker/evaluator/model tests prove source order, expression typing,
  duplicate/malformed diagnostics, one evaluation per `show`, omitted false,
  explicit/dynamic true/false, and exact resolved Boolean propagation.
- Actual HTML/preview, PDF, and DOCX artifacts prove false/omitted table absence,
  including browser JSON/ARIA/alt/reference absence and native/fallback DOCX
  paths. True/dynamic true preserve exact table contents and ordinary table views.
- Example 07 executes with existing exports; all four visibility states appear
  correctly in each approved output format; migration text is present and exact.
- No CSS-hidden, screen-reader-only, hidden JSON, offscreen, or alternate table
  representation qualifies as false omission.

## Affine End-to-End

- Registry/declaration PI/E, scalar/affine composition, aliases/imports/editor
  metadata, and S117 finite/source diagnostics reconcile with runtime.
- C/F/K invariant, conversion/round-trip, ordering/equality, same/mixed left-unit
  subtraction, rejection rules, sum/mean/min/max/abs/round/unary behavior all
  execute with accepted values and units.
- Mixed-unit chart normalization preserves first display unit and existing
  labels/nulls/order in model and artifacts.
- External atomic/alias C/F data and exact `{ value, unit }` JSON/CSV round trip;
  affine compound external text and extra/missing fields reject with accepted
  AMX4004/AMX4005 behavior.
- SI library remains 16 dimensions/50 exports; the four temperature declarations
  and aliases import and execute. Example 05 and V0.19 spec match runtime.

## Root, Build, Editors, and Broad Gates

- Exact master focused command executes and raw pass/fail/assertion counts are
  recorded. Supplemental measurement/data/example selection is executed if
  separately included, so no V0.19 stream is left to implication.
- Broader `bun test` executes if approved and its full aggregate plus unrelated
  failures/retries/skips remain raw. A narrower subset never substitutes for it.
- Root build and no-emit typecheck pass, or exact failures/residuals are recorded;
  generated browser runtime provenance/hash/diff is reviewed and no hand edit is
  accepted.
- Full configured VS Code host command is recorded with exact aggregate. V0.19
  TextMate/format/diagnostic cases are separately identified. A new or unchanged
  Windows cleanup/path aggregate failure remains raw/residual, not PASS.
- Desktop typecheck executes or is BLOCKED/UNAVAILABLE. Focused V0.19 Vite UI
  executes and is labeled harness evidence; native/cross-platform claims remain
  unavailable unless separately authorized and directly proven.

## Docs, Examples, and Artifacts

- V0.19 spec/README are additive and exact; historical specs are unchanged;
  migration does not claim auto-conversion or hidden-table fallback.
- Examples 05/07 CLI/source evaluation, formatting, named outputs, navigation,
  and output artifacts all pass or have exact raw evidence/residuals.
- HTML/PDF/DOCX and logs have exact paths, hashes, sizes, commands, CWD, host/tool
  versions, and structural/visible inspection results.
- Performance/resource observations are reported only as one-host evidence; no
  platform capacity, release readiness, or certification threshold is inferred.

## Evidence, Residuals, and Scope

- `integrated-evidence-matrix.md` contains every row with raw status, counts,
  artifacts, failures/retries, residual owner, and separate disposition.
- No first failure, unavailable command, or unrelated aggregate failure is
  deleted or silently reclassified. No PENDING/NOT RUN row is called PASS.
- S119's extension-host residual and any native/broad/generated/root residual
  is reconciled separately, with owner and downstream impact.
- Final changed-path/preservation audit proves S120 itself changed only approved
  planning/evidence/artifacts and did not alter product behavior.
- No package/version, release, publication, deployment, installer, distribution,
  Marketplace/registry, or platform certification action occurs.
- A separate product-owner disposition ACCEPTS/CLOSES, ACCEPTS WITH RECORDED
  RESIDUALS, or BLOCKS/OPENS V0.19. That disposition alone authorizes no release
  or package/platform work.
