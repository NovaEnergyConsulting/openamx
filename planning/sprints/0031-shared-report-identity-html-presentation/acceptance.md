# Sprint 031 Acceptance Criteria

Sprint 031 is complete when:

- An immutable typed shared report model carries resolved identity, sanitized logo bytes/alt, final-environment narrative and source/view emissions in original order from one evaluated document; HTML consumes it without re-parsing, re-loading inputs/modules or reevaluating. A documented API/boundary is ready for Sprint 032 PDF/DOCX; no branded PDF/DOCX layout is claimed prematurely.
- Existing version-1 `.openamx/project.json` `inputs` semantics and local/per-run precedence are unchanged. Optional project `report`, frontmatter `report`, field-by-field precedence, neutral defaults and top-level title follow the approved V0.5 contract. Unknown/duplicate/invalid fields, missing root, bad `logoAlt`, invalid types and masked-invalid project values fail in the approved order with `AMX6001`/`AMX6002`, project JSON pointer or original YAML UTF-16 location and bounded private-path-safe messages.
- CLI `render` and `export pdf|docx` support explicit optional `--project-root` for identity only, while no-option paths, input mapping working-directory semantics and `run` remain unchanged. Desktop main-process report operations use the selected canonical project root without webview asset/config authority. Failed analysis/config/assets do not alter existing report or named-output destinations.
- Local PNG/JPEG logo handling enforces the approved path/symlink/regular-file/signature, 256 KiB source, 1024-pixel-axis/1,048,576-pixel area and 1 MiB sanitized PNG limits. Metadata/filename and external paths are absent from HTML; missing/unreadable/unsupported/traversal/mismatched assets fail before writes and never trigger network loads. Effective logo requires correct descriptive alt. Accent syntax/contrast and deterministic neutral text/focus fallback are tested without recoloring chart data.
- HTML shows semantic header/main/footer, escaped title/publisher/author/status/classification/footer, inline bounded logo/alt, readable narrative and source, accessible table/chart framing, focus/empty states and offline assets. `sourceVisible` defaults to true, explicit false removes only formatted listings and preserves narrative/views/data at original positions; no secrecy claim is made.
- For fixed evaluated source/identity/input data, HTML structure is deterministic and works at 360 and 1280 px, 200% zoom and print without overlapping content. HTML sorting/filtering/pagination, stable/null-last behavior, keyboard use, original-order print data, four existing chart kinds and textual alternatives remain intact; V0.2-V0.4 documents with no V0.5 identity retain their values, order and visible source.
- Focused renderer/asset/config/CLI/browser and no-write regression checks pass, as do root `bun run build`, `bun test`, relevant desktop direct/RPC/typecheck/Vite checks and `git diff --check` where supported. Record exact commands/results and any unavailable checks, plus the Sprint 032 adapter handoff in planning logs. Sprint 034 retains manual visual sign-off.
- Sprint 029 native workflow and Sprint 030 editor exceptions remain individually tracked; inherited V0.4 native platform/Hutch, Office and license/Marketplace residuals are not reported as passed by Sprint 031 tests.
