## Builder Task After Authorization

- Implement a Bun-main-process updater coordinator around the pinned
  Electrobun API. Keep calls out of renderer code and isolate the coordinator
  behind an injectable adapter for focused tests.
- Provide typed RPC/state for current state, explicit checks, and
  user-authorized download/preparation. Do not add an apply/restart RPC.
- Start exactly one check for a supported packaged stable build and share the
  same state machine with explicit check requests. Do not schedule checks.
- Gate unsupported/development configurations before any production host
  request. A check may report an available version but must never download.
- Coalesce overlapping checks/downloads and test no-update, available,
  failures, ready state, unsupported builds, and duplicate requests.
- Leave the current quit guard unchanged. Do not edit Vue/UI, menu/help,
  release docs, or release scripts under this sprint.
- Record exact tool versions, commands, outputs, first failures/retries,
  hashes, and residuals under the authorized S129 evidence root.

## Stop Conditions

Stop on any public-host request in a test, unexpected startup download,
duplicate native work, update/app identity or channel mismatch, need to edit
an out-of-scope file, or any attempt to add prompt/apply/restart behavior.
Request a scope amendment before continuing. Preserve every first failure and
retry; there is no retry cap, but retries do not authorize scope expansion.

Sprint 130 owns the Help command, prompt, consent UI, `applyUpdate()` and
quit-safe staged-update retry. S129 acceptance grants no release,
publication, deployment, or platform certification authority.
