- Sprint 090 is contract and inventory work only. No production implementation
  or corpus migration is authorized.
- Preserve the existing offline and safe local-link confirmation behavior.
  Do not propose remote content, wider path permissions, or new renderer/link

  explicit purpose/reproducibility/test criteria and preserve artifact
  provenance; the kitchen-sink PDF remains immutable.
- Do not redesign the desktop UI. Specify discoverability through existing
  Welcome/Starter Examples affordances and maintain a clear distinction
  between the guide and the compact Hello/Operations Note starters.
- Do not claim runtime, rendering, packaging, native desktop, release, or
  platform-certification acceptance based on document inspection.
