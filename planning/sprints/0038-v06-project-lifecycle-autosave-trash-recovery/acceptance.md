# Sprint 038 Acceptance Criteria

Sprint 038 is complete when:

- Safe enumeration returns only permitted contained regular AMX, CSV, JSON, settings, and generated HTML/PDF/DOCX records; symlinks, internal state, trash, ignored/generated/build paths, path substitutions, and unsupported shapes are excluded and tested.
- Explicitly mapped external input files appear in a labeled private/external section and can be opened only through an explicit bounded main-process operation. No general external filesystem browsing or webview path authority is introduced.
- Create Project preflights and atomically creates a valid version-1 `.openamx/project.json` and minimal valid `.amx` report, with no partial files on failure. Create file/folder, duplicate, reveal/open externally, and generated-output actions are typed, bounded, and tested.
- Rename/move/drag updates affected contained relative AMX imports transactionally. Tests cover multiple dependents, nested paths, current revisions, destination collisions, outside-root/symlink/ambiguous imports, stale disks, cancellation, successful commit, and rollback with no partial imports or moves.
- Delete moves files/folders to ignored `.openamx/trash` with sufficient restore metadata. Restore and explicit empty-trash handle collisions, open/referenced files, nested folders, stale changes, and permanent deletion safely. No trash/internal state appears as a normal project file.
- Delayed autosave is configurable and applies to contained files and explicitly opened external input files. It writes exact valid or invalid text, uses disk-hash conflict detection and atomic replacement, retains explicit Save, and pauses on unresolved conflict.
- Conflict states offer compare, reload, discard, and keep-editing with clear outcomes. Project switch and quit/close guard dirty/conflicted tabs through Save All, Discard All, or Cancel; failed/cancelled saves retain buffers, current project, and retry capability.
- Private crash snapshots preserve unsaved buffers and recovery metadata locally. Startup offers inspect/restore/discard, restore does not automatically overwrite project source, snapshots are cleaned up safely, recents/layout/preferences are bounded, and no source/input/private-path/recovery content enters shared project configuration.
- Project generation and Sprint 036 request identity invalidate active jobs across project switches, restore/discard, rename/move, and destructive operations. Late/cancelled work cannot update a new project/tab or write an output.
- Webview authority remains bounded: filesystem, native dialogs, process, evaluator, loader, arbitrary path, trash, recovery, and final-write authority stays in trusted Bun services. Direct authority tests pass.
- Focused desktop lifecycle/RPC/recovery tests, root compatibility tests, typecheck/Vite/direct desktop checks, and restart/conflict/no-write fixtures are run and recorded with commands, versions, counts, artifacts, warnings, and unavailable-host limitations.
- Direct native host checks cover available Open/Create/Save/Reveal/window-close/quit flows where an SDK-enabled host exists. Missing native host evidence, Hutch/package checks, and target-platform release checks remain explicitly unavailable or blocked rather than passed.
- `planning/state.md`, `planning/decisions.md`, `planning/questions.md`, and Sprint 038 evidence record all implementation decisions, residuals, performance/recovery observations, native limitations, and Sprint 039 entry conditions. Inputs/report-settings, editor intelligence, data editing, final preview/export, and onboarding are not claimed complete.
- Final status is `COMPLETE`, `COMPLETE WITH RECORDED EXCEPTIONS`, or `BLOCKED`; no native release, Office, license/Marketplace, or formal accessibility certification is inferred.
