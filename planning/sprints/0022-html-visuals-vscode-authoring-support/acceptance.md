# Sprint 022 Acceptance Criteria

Sprint 022 is complete when:

- Every `show` appears after its owning executable block's visible escaped/formatted AMX source, in statement order at the fence's narrative position; declarations without `show` emit nothing. Repeated shows use captured snapshots, including mutations after earlier shows, without re-executing the document.
- A report with no V0.4 views still produces the same V0.2/V0.3 HTML and CLI results; final-environment interpolation, inert narrative/ordinary fences, named JSON/CSV exports, and invalid-analysis no-write behavior remain intact.
- Table HTML exposes a caption, scoped headers, keyboard-operable sorting with accurate `aria-sort`, escaped cell content, case-insensitive displayed-text filtering, default 25/page with 10/25/50 choices, page-reset behavior, live range/count status, and distinct source-empty versus filter-no-match states.
- Browser interaction tests demonstrate stable typed ascending/descending sorts (number, Boolean, String, DateTime), null-last ordering and original-order tie resolution; filtering and pagination change only visible rows, not AMX values or the print output.
- Bar, column, line and scatter charts bind the exact show-time data: source/series/first-seen group order, one-based scalar labels where omitted, preserved repeated categories, null gaps, omitted nullable scatter points, inspectable values, and deterministic empty states. Charts have accessible figure names/descriptions and text/tabular data alternatives; colors alone do not distinguish series.
- Print output is noninteractive and deterministic: all table rows in original order with captions/headers, static chart representations with labels and full textual data, no dependency on transient UI state, and no remote assets. Rendering tests verify stable output and print-specific structure; PDF file/layout acceptance remains Sprint 023.
- All user-controlled table/chart titles, labels, descriptions, cell values, chart data, and executable source are escaped correctly in HTML, client payloads and SVG; a tested malicious label/value cannot become active markup/script. Standalone reports operate without network access.
- Formatter output for V0.4 declarations and `show` is parser-valid and idempotent. Extension formatting edits only exact executable `amx` content; CRLF, narrative, front matter and ordinary fences remain unchanged.
- VS Code direct providers complete V0.4 keywords, earlier view names and valid contextual fields/options where known, omit later/out-of-scope/narrative-only names, and report/clear parser, checker and local-link diagnostics at original UTF-16 locations on unsaved buffers. They do not evaluate AMX or read CSV/JSON input data.
- Focused renderer/formatter/browser and extension host tests pass; root `bun run build`, `bun test`, extension `bun run compile`, `bun run test`, `git diff --check` pass. Record exact versions/counts and any unavailable interaction or host checks; do not claim a gate passed if it was not run.
- Sprint 023 receives a stable static visual/data representation, but no PDF command, native desktop workflow, DOCX export, or Marketplace publication was added.
