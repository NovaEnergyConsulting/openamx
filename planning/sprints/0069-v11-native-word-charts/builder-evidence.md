**Mixed-group scatter deferral:** a scatter chart with a null-only group and another plottable group cannot be passed to the installed `ChartRun`; its constructor rejects `Series "Group A (all coordinates null)" has no points`. The user approved omitting the whole chart with a clear unsupported-group notice and complete table. This does not authorize dropping only the empty group or changing shared chart semantics.

**Numeric-X line no-coordinate series rule:** when a numeric-X line has some plotted series and another series with no plottable XY pairs (all-null Y or values paired only with null X), omit only that series from the native XY chart, retain all table rows/columns, and disclose the omission in the chart description. This is a DOCX-only disposition; charts with no plottable coordinates use the whole-chart no-data policy.

The numeric-line category-spacing mismatch was reproduced in Word desktop. A candidate native `c:lineChart` OOXML encoding using numeric X/Y values opened in Word with its series data empty and failed. The subsequently approved XY scatter-with-straight-lines representation retained the numeric data in desktop Word. The underlying OOXML chart kind differs only for numeric-X OpenAMX `line` charts; the shared model and OpenAMX meaning remain unchanged. No category substitution, fabricated points, unapproved row omission, or static-image fallback was implemented.
