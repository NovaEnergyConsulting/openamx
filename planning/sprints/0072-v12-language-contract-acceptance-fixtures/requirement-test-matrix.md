## Test boundaries

- Sprints 073–075 add executable feature tests alongside their implementations; this matrix does not add expected-red tests to the normal suites.
- Sprints 076–077 add integration assertions only in the repository's existing formatter/editor/acceptance suites; no parallel test framework is proposed.
- Existing diagnostics are pinned only where their catalog semantics apply. New diagnostic identities listed as unallocated in the diagnostic matrix must be approved before the related production diagnostics and exact-code tests are implemented.
- Source-coordinate assertions use the original complete fixture document, including front matter and the executable fence. Module assertions use the named module document's own 1-based UTF-16 coordinates.
