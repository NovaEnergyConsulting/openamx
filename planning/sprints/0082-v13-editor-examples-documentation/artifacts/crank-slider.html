Crank-slider mechanism

This schematic shows a crank pin following one full circular path and driving
a piston through a fixed-length connecting rod. Its time parameterization is
non-uniform; the equations use only existing AMX arithmetic, abs, conditional
expressions, and sqrt, with no trigonometric functions.

let crankRadius: Number = 34
let rodLength: Number = 105
let pivotX: Number = 70
fn crankX(t: Number, r: Number): Number = r * (1 - 2 * abs(t - 1))
fn crankY(t: Number, r: Number): Number = if t <= 1 then sqrt(r * r - crankX(t, r) * crankX(t, r)) else -sqrt(r * r - crankX(t, r) * crankX(t, r))
fn sliderX(t: Number, pivot: Number, r: Number, rod: Number): Number = pivot + crankX(t, r) + sqrt(rod * rod - crankY(t, r) * crankY(t, r))

The crank equations parameterize a complete revolution over t = 0 to t = 2.
The rod-length constraint determines the slider position directly for every
selected time; the document does not model accumulated simulation state.
